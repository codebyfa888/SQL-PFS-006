Constraints
-------------
constraints are rules applied to a table columns in MYSQL to ensure that only valid and accurate data is stored in the database.

in simple words
---------------
constraints = rules that control the data entered into a table.

why do we use constraints?
-------------------------
constraints are used to 
1.maintain data integrity
2.prevent invalid data integrity.
3.avoid duplicate records
4.ensures relationships between tables,
5.make the database reliable and consistent.
  
integrity constraints
---------------------
1.not null
----------------
==> the not null constraints ensures that a column cannot contain Null(empty)values. Every row must have a value for that column. ==>not null: doesn't allow null values.
----------------
2.unique
----------------
==> the unique key constraint ensures that all values in a column are different, duplicate values are not allowed.
----------------
3.primary key
==> It is combination of unique and not null constraints. 
----------------
4.composite key
==> if we applied more than one primary key then we should use composite key constraint, this is only applicable for table level not a column level.
----------------
5.foreign key
==> A foreign key creates a relationship between two tables. it ensures that value in the child table must already exists in the parent table.
----------------
6.default
==> the default constraint automatically assigns a predefined value if no values is provided during insertion.
----------------
7.check
==> the check constraint ensures that values satisfy a specified condition before insertion or update. 
----------------





Referential actions
===================

referential actions define what happens to a child table data when parent table data is updated or deleted.

on delete cascade, on update cascade

on delete set null on update set null
