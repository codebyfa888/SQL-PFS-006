MySql operators:
================
operator is a symbol it performs specific task.
syntax:
-------
operand operator operand
 a         +        b

types of operators
==================

1.arthematic operators
----------------------
(+,-,*,/,%)


2.comparision operators
-------------------------
(=,!=,<,>,<=,>=)

3.logical operators
------------------------
logical and --> if both true return true ==>Both are True


logical or --> if both are false return false ==>At least one is True

logical not --> if true it will return false/if false it return true(negation) ==>Reverses the result
